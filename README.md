# Creating-a-Suspicious-Network-Connection-Ticket-and-Assigning-It-To-a-SOC-L1
A suspicious outbound network connection was detected from an internal workstation to an unfamiliar or potentially malicious external IP address.
![Image alt](https://github.com/Kevinolee1/Creating-a-Suspicious-Network-Connection-ticket-and-assigning-it-to-a-SOC-L1/blob/802a0d762b686f5e70a3fd864a88048e6105ed94/Screenshot%202026-08-18%20191322.png)
Select “Open New Ticket” to create a new support ticket.
![Image alt](https://github.com/Kevinolee1/Creating-a-Suspicious-Network-Connection-ticket-and-assigning-it-to-a-SOC-L1/blob/ee52739e53c1db307151ae09cda6ef6f2a13fde5/Screenshot%202026-08-16%20013107.png)
Enter the victim’s name and email address. In the Help Topic field, select Security Incident. Then, provide a clear and concise description of the issue in the Issue Summary field.
![Image alt](https://github.com/Kevinolee1/Creating-a-Suspicious-Network-Connection-ticket-and-assigning-it-to-a-SOC-L1/blob/1d1bd6ce491ae45e91386bacd983efa7fbed24e8/Screenshot%202026-08-16%20013502.png)
Select “Create Ticket” to initiate the ticket creation process.
![Image alt](https://github.com/Kevinolee1/Creating-a-Suspicious-Network-Connection-ticket-and-assigning-it-to-a-SOC-L1/blob/5a786836253aeb3e1facd961d6c16aee02c0461c/Screenshot%202026-08-18%20011200.png)
Authenticate to the administrative account.
![Image alt](https://github.com/Kevinolee1/Creating-a-Suspicious-Network-Connection-ticket-and-assigning-it-to-a-SOC-L1/blob/fc17fd3f4fca9b73e828ec0585af2dfc6fd6a522/Screenshot%202026-08-16%20013759.png)
Updated the ticket priority to High to reflect the potential severity and business impact of the suspected data exfiltration activity.
![Image alt](https://github.com/Kevinolee1/Creating-a-Suspicious-Network-Connection-ticket-and-assigning-it-to-a-SOC-L1/blob/f407ebf4a1507b1a294e38db8db5f7ba92b7cc03/Screenshot%202026-08-16%20013900.png)
Assign the ticket to a SOC Level 1 Analyst for initial investigation and triage.
